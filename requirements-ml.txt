# Machine-learning dependencies (Phase 4).

# Kept separate from requirements.txt on purpose: these are large - LightGBM,
# pandas, NumPy and MLflow together are several hundred megabytes - and nothing
# in the stream layer, the API's search path or the booking layer needs them.
# Someone who only wants to run the pipeline and search should not have to wait
# for them.
#
#     pip install -r requirements.txt        # stack, API, booking, tests
#     pip install -r requirements-ml.txt     # adds training and /predict
#
# Without these installed the system still runs; GET /predict returns 503 with
# an explanation rather than crashing, and the ML tests skip.
